# Medical Gas Training Institute - Static Site

A static recreation of the Medical Gas Training Institute website (https://www.medgasinstitute.com/) built with Bulma CSS framework.

## Features

- Responsive design using Bulma CSS framework
- Mobile-friendly navigation with hamburger menu
- Clean, modern styling
- All original content and structure preserved
- Fast loading static HTML

## Getting Started

Simply open `index.html` in your web browser to view the site.

## Structure

- `index.html` - Main homepage with all content and styling
- Uses CDN links for Bulma CSS, Font Awesome, and Google Fonts

## Original Content

The site contains information about medical gas certifications including:
- ASSE 6005 (Medical Gas Systems Generalist)
- ASSE 6010 (Medical Gas Systems Installer)
- ASSE 6020 (Medical Gas Systems Inspector)
- ASSE 6030 (Medical Gas Systems Verifier)
- ASSE 6040 (Bulk Medical Gas Systems Verifier)
- ASSE 6050 (Medical Gas Systems Brazer)
